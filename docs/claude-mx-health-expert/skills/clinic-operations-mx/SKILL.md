# Clinic Operations Mexico

## Method
1. Determine facility type.
2. Determine services actually offered.
3. Apply baseline health-law obligations.
4. Add infrastructure NOM according to facility type.
5. Add service-specific NOMs.
6. Separate software-enabled evidence from physical/operational compliance.

## Service packs
- general outpatient -> NOM-005 where applicable
- specialized/hospital -> NOM-016 where applicable
- lab -> NOM-007
- anesthesia -> NOM-006
- ambulatory major surgery -> NOM-026
- emergency -> NOM-027
- ICU -> NOM-025
- dental -> NOM-013
- blood/transfusion -> NOM-253
- RPBI -> NOM-087
- radiology -> current applicable radiological regulation

## Output
For facility audits, produce checklist with requirement, evidence type, owner, frequency, criticality and corrective action.
