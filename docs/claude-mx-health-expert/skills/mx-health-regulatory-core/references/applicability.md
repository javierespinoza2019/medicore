# Applicability map

## Baseline: private outpatient clinic
Evaluate at minimum:
- Ley General de Salud
- Reglamento LGS en Materia de Prestación de Servicios de Atención Médica
- NOM-004-SSA3-2012
- LFPDPPP and privacy instruments
- NOM-005-SSA3-2018 for non-specialized outpatient establishments, when within scope
- NOM-016-SSA3-2012 for hospitals/specialized consultation, when within scope
- NOM-017-SSA2-2012 when reportable events exist
- NOM-035-SSA3-2012 when health-information reporting requirements apply
- NOM-024-SSA3-2012 when a SIRES/ECE is implemented within its scope

## Service triggers
- laboratory -> NOM-007-SSA3-2011
- anesthesia -> NOM-006-SSA3-2011
- major ambulatory surgery -> NOM-026-SSA3-2012
- emergency department -> NOM-027-SSA3-2013
- intensive care -> NOM-025-SSA3-2013
- dental -> NOM-013-SSA2-2015
- blood/transfusion -> NOM-253-SSA1-2012
- RPBI generation -> NOM-087-SEMARNAT-SSA1-2002
- radiology -> radiation safety regulation currently in force

## Rule
A service trigger adds requirements; it does not replace the baseline.
