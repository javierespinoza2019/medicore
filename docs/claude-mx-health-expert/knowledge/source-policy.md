# Política de fuentes y vigencia

## Jerarquía de fuentes
1. Diario Oficial de la Federación (DOF)
2. Cámara de Diputados — LeyesBiblio
3. Secretaría de Salud / DGIS / COFEPRIS / CENETEC
4. Autoridad estatal competente
5. Organismos de estandarización para estándares voluntarios
6. Fuentes secundarias sólo para orientación; nunca como única evidencia de vigencia

## Reglas
- Guardar URL, título, fecha de publicación, fecha de última reforma y fecha de verificación.
- No inferir vigencia por antigüedad.
- Si existe contradicción entre una copia secundaria y una fuente oficial, prevalece la fuente oficial.
- Para reformas, reconstruir el texto vigente; no usar sólo la publicación original.
- Tratar proyectos de NOM por separado del texto vigente.
