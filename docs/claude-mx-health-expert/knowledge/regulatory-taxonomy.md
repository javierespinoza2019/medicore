# Taxonomía regulatoria

## Nivel de fuerza
1. Constitución
2. Ley
3. Reglamento
4. Norma Oficial Mexicana
5. Acuerdo, lineamiento, disposición administrativa obligatoria
6. Guía/criterio técnico
7. Estándar internacional o sectorial voluntario
8. Política/control interno

## Tipos de obligación
- documental
- clínica
- operativa
- infraestructura
- privacidad
- seguridad
- interoperabilidad
- reporte/notificación
- conservación
- habilitación profesional
- autorización sanitaria

## Estados de aplicabilidad
- obligatorio general
- obligatorio condicional
- recomendado
- no aplica
- requiere interpretación jurídica

## Estados regulatorios
- vigente
- modificado
- sustituido
- cancelado/derogado
- proyecto
- desconocido / pendiente de verificación
