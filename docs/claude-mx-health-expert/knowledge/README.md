# Base de conocimiento — Salud digital y clínicas privadas en México

Esta base está diseñada para que Claude opere con conocimiento regulatorio modular, versionado y verificable.

## Dominios
- Expediente clínico
- SIRES / expediente clínico electrónico
- Privacidad y datos personales
- Seguridad de la información
- Interoperabilidad y terminologías
- Operación de establecimientos
- Vigilancia epidemiológica e información en salud
- Servicios especializados
- Evidencia electrónica, conservación y firma
- Medicamentos y dispositivos
- Gobierno regulatorio del producto

Nunca responder desde memoria general cuando la pregunta dependa de vigencia normativa. Verificar fuente oficial y fecha.
