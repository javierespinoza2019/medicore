# Modelo de control auditable

Cada requisito debe poder expresarse con los siguientes campos:

- requirement_id
- regulation_id
- title
- legal_force
- source_section
- requirement_text
- interpretation
- applicability_rule
- facility_types
- services
- professional_roles
- system_modules
- required_data
- workflow_control
- operational_control
- evidence
- responsible_role
- priority
- test_case
- retention_rule
- reporting_rule
- effective_from
- effective_to
- source_url
- last_verified_at
- status

## Regla funcional
No considerar un control completo si falta evidencia verificable o prueba de aceptación.
