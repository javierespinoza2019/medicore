Documento Técnico del Sistema — MediCore
Plataforma Integral de Gestión Clínica
Versión: MVP completo (Fase 1–5 terminadas) · Fecha de referencia: 2026-08-21

1. Resumen Ejecutivo
MediCore es una plataforma SaaS empresarial para la gestión integral de clínicas privadas, diseñada para cubrir el ciclo completo de atención del paciente: registro → agenda → recepción → triage → consulta → diagnóstico → receta → estudios → dispensación → cobro → facturación → expediente clínico, con capas transversales de normatividad sanitaria, seguridad (RBAC + auditoría), interoperabilidad (HL7 FHIR) e inteligencia operativa (reportes).

La arquitectura está orientada a evolucionar desde un Centro Médico / Clínica hacia un Hospital completo (hospitalización, farmacia, laboratorio, imagenología, quirófanos, UCI).

2.3 Patrón de Estado Compartido
Los módulos que necesitan datos en tiempo real entre pantallas usan un patrón de estado compartido a nivel módulo con listeners:

Una lista mutable compartida (sharedAppointments, sharedEstudios, sharedUrgencias).
Un Set de listeners suscritos vía useEffect.
Funciones globales de mutación (updateAppointmentGlobal, addEstudioGlobal, etc.) que notifican a todos los suscriptores.
Hooks reactivos (useAppointmentsState, useEstudiosState, useUrgenciasState) que disparan re-render mediante un tick.
Esto garantiza que, por ejemplo, Triage ↔ Urgencias ↔ Sala de Espera y Consultas ↔ Estudios operen sobre la misma lista y se sincronicen sin recargar.

4. Seguridad y Control de Acceso
4.1 Autenticación
AuthProvider (React Context) gestiona sesión, persistida en localStorage.
Guard de autenticación: redirección a /login sin sesión activa.
login(email, password) valida contra usuarios activos; loginAs(userId) para cambio rápido de rol (demo).
Selector de sucursal activa con persistencia; sincronización entre pestañas vía evento storage.
4.2 Roles (RBAC — 8 perfiles)
Rol	Etiqueta	Alcance principal
admin	Administrador	Acceso total, incluye HL7, seguridad y normatividad
directivo	Directivo	Todo menos edición clínica; sí auditoría, usuarios y reportes
medico	Médico	Flujo clínico completo (consulta, receta, estudios, triage)
enfermeria	Enfermería	Triage, urgencias (vista), notas de enfermería
recepcion	Recepción	Agenda, sala de espera, pacientes, caja
caja	Caja y Cobros	Cobros, cortes, facturación, farmacia, estudios
farmacia	Farmacia	Dispensación, recetas, estudios
laboratorio	Laboratorio	Estudios, resultados
4.3 Matriz de Permisos (2 niveles)
Por ruta (roleRoutes): controla qué pantallas puede abrir cada rol, con soporte de prefijos (/app/pacientes/, /app/normatividad/).
Por acción (rolePermissions): control fino de 17 capacidades (crear/editar/eliminar paciente, cobrar, cerrar caja, dispensar, administrar usuarios, ver auditoría, exportar, etc.).
4.4 Auditoría
Bitácora de trazabilidad con registro de usuario, acción, módulo, registro afectado, IP y resultado, con filtros y exportación.
